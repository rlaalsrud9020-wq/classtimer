# ⏱️ 수업 활동 교실 TV 타이머 (Class Timer)

수업 활동 시간에 교실 TV 및 대형 스크린에 띄워두고 사용하는 웹 타이머입니다.

## 🌟 주요 기능
- **직관적인 시간 프리셋**: 5분, 10분, 15분 버튼 원클릭 즉시 시작
- **직접 입력 모드**: 분/초 단위 사용자 정의 설정
- **초대형 고대비 숫자**: 교실 맨 뒤에서도 한눈에 보이는 가변 폰트 크기
- **1분 남음 시각 경고**: 1분 이하가 되면 숫자 색상이 강렬한 빨간색으로 자동 변경
- **종료 효과**: 시간이 끝나면 화면 전체 깜빡임 + "시간 끝!" 문구 + 알림음
- **수업 편의 기능**: 일시정지/재개, 초기화, 알림음 켜기/끄기 토글, 전체화면(⛶) 모드
- **정확도 보장**: Wall-clock(Date.now) 기반 연산으로 탭 전환 시에도 오차 없음

## 📁 구조
- `index.html`: 메인 타이머 웹 애플리케이션
- `style.css`: 반응형 대형 디스플레이 스타일시트
- `timer-core.js`: 타이머 핵심 연산 및 검증 로직
- `timer.js`: UI 이벤트, Web Audio 알림음 및 화면 제어
- `tests/`: 단위 테스트 스위트
